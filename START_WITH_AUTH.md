# 🚀 Быстрый старт с аутентификацией

## ✅ Всё готово! Просто запустите:

### 1. Убедитесь что backend запущен

Если остановили, запустите:
```bash
cd backend
npm run dev
```

### 2. Запустите frontend (если остановили)

```bash
# В новом терминале, из корня проекта
npm run dev
```

### 3. Откройте браузер

http://localhost:5173

## 🔑 Демо-аккаунты уже созданы!

Можете войти под любым из них:

### 👨‍💼 Admin (полный доступ)
- **Email**: admin@campus.edu
- **Password**: password

**Возможности:**
- Управление всеми отчётами
- Изменение статусов
- Управление пользователями
- Назначение ролей
- Удаление отчётов
- Детальная статистика

### 🔧 Technician (техник)
- **Email**: tech@campus.edu
- **Password**: password

**Возможности:**
- Просмотр всех отчётов
- Изменение статусов
- Фильтрация и поиск

### 👨‍🎓 Student (студент)
- **Email**: student@campus.edu
- **Password**: password

**Возможности:**
- Создание отчётов
- Просмотр своих отчётов
- AI-помощник

## 🎯 Что попробовать:

1. **Войдите как Student**
   - Создайте 2-3 тестовых отчёта
   - Попробуйте AI-помощника

2. **Выйдите и войдите как Technician**
   - Посмотрите все отчёты
   - Измените статусы на "In Progress"

3. **Войдите как Admin**
   - Посмотрите дашборд со статистикой
   - Управляйте пользователями
   - Измените роль пользователя
